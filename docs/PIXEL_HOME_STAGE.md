# Pixel farm home stage

This branch applies the approved cozy pixel-farm visual direction to the existing Quest home screen without changing the underlying Quest data model.

Mobile changes include:
- farm hero using the approved Quest farm artwork
- existing daily clock reskinned as a wooden pixel clock
- XP circle/strip treatment
- anchors restyled as a horizontal daily timeline
- today's quest list reskinned in pixel UI
- farm-status/streak visual panel
- existing Voyage Adjustment action presented as the Stop Day control
- existing navigation presented as a bottom mobile game nav

Desktop remains on the previous layout for now. The dedicated Quests / Anchors / Stats / More pages are intentionally not part of this stage.
